How the Physical Keyboard Polling Works:

Press and hold any key on your physical keyboard. The browser captures the keystroke, updates the emulator’s keyboard register at address 24576, and the running Box.hack machine loop writes −1 into screen rows 22 to 41. Releasing the key writes 0 and erases the box.
